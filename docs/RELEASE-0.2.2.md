# dsh-amphoreus 0.2.2

适配并验证 amphoreus-skill-suite v1.6.0，同时保留 DSH 0.1.2-alpha.4 的运行兼容性。

## 更新与适配

- 套件验收固定到 v1.6.0、提交 `fd01e56ce929fbad2d38011adab20df8a0234065`。该版本的技能合同延续 v1.5.0，v1.6.0 主要更新套件的表情资源和展示页面。
- 圆桌与陪聊的 `<details><summary>台账</summary>` 默认折叠，角色发言与审计件分开显示；支持同一行和多行外壳。
- 识别折叠台账中的末行回执，避免关闭标签导致回执漏记；原正文和日志保持原样。
- 代码围栏中的示例不会变成活动台账；其他 HTML、属性和脚本仍转义。支持反引号和波浪线围栏。
- 角色系统提示词补齐外部 `relations.md` 的绝对路径；来源跟随有效技能根和配置的关系文件路径。
- 全席征询明确采用“各席独立作答”，与套件圆桌的用户指定作答方式合同一致。
- CI 与发布质量门读取固定上游套件，执行真实解析测试；技能正文和图片不打包进 npm。

## 安装

```bash
dsh plugin --profile web add dsh-amphoreus@0.2.2
```

升级后重启 DSH Web，并刷新页面。更新外部套件时，建议让 `skillRoots` 指向套件仓库的 `skills/` 目录；Git 指纹可在插件设置中核对。

## 验证

- 上游静态校验：13/13 角色卡、18/18 路由清单、13 份评测卷和65个场景，PASS。
- 插件全量回归连同真实套件合同：401项通过、0失败、0跳过。
- 发布产物验证：397项检查通过。
- 本地真实模型全席征询：13/13完成、13/13单次角色回复、通用身份首答0、双回复0；浏览器13个台账默认收起，展开与收起实测通过。
- 覆盖台账折叠、回执识别、围栏代码、任意HTML转义、角色资料路径及既有归档和会议功能。

## 使用边界

全席征询为独立并行征询，不是角色自动交错对话。会议汇总仍为页面内存态。台账按模型返回的固定结构呈现，角色声线和篇幅仍由外部技能及实际模型输出决定。
