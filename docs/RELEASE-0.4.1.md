# dsh-amphoreus 0.4.1

兼容 δ-me13 skill v1.8.0 的工作方法与角色合同，宿主基线保持 DeepSeek Harness 0.1.6-alpha.2。

## 技能套件

CI 和发布检查固定使用 δ-me13 skill v1.8.0 的提交 `4ecfa005d61db118518deff8512aaeadd04cc478`。真实套件测试覆盖十三卡解析、外部参考资料路径、卡正文保真、工作方法内核的可读取性与内容完整性，以及缺席和移交格式。

插件继续从 `skillRoots` 只读加载角色卡、共享合同和表情。工作方法由外部技能定义，角色身份、口吻与立场继续遵循各卡；npm 包不包含技能正文或美术资源。

## 升级

```bash
dsh plugin --profile web add dsh-amphoreus@0.4.1
```

插件安装后重启 DSH。另将配置的外部技能套件完整更新到 [δ-me13 skill v1.8.0](https://github.com/xi-kari/delta-me13-skill/releases/tag/v1.8.0)，在设置中重新解析套件并核对目录和指纹，然后建立新席位会话。已有会话首轮注入的卡正文不会被追溯替换。

保留 `amphoreus` / `amphoreus-*` 调用入口、既有席位绑定、会话和插件数据。宿主与插件的版本分别管理。

## 验证范围

在固定的 v1.8.0 套件上，本地发布检查通过 628 项测试，无失败、无跳过；类型检查、构建及 587 项产物检查通过。旧版 v1.7.0 套件作为负控时，新版工作方法内核检查按预期失败。

插件的解析、注入、类型检查、构建和分发检查，与上游模型行为评测分别记录。上游的 65 题成绩不代表本插件在 DSH 中重新完成了同一评测；实际角色输出和图片显示依赖模型及客户端。
